## MacDock v1.8
### Added
- **Screenshot and screen record** buttons in the menu bar and as Control Center tiles (independent toggles in Settings).
- **Launchpad sort by install date.**
- **Control Center dark mode tile**; tiles can be edited, removed, added, reordered by drag and drop, and resized.
- **Hide Start icon** option, **dock corner radius** setting, and a new **Recycle Bin icon**.

### Fixed
- Scrolling in folder fans and Settings.
- Launchpad context menu flips to stay on screen.

Install: extract `MacDock-v1.8.zip` and run `Install.bat`.
