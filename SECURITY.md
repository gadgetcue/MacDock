# Security policy

## Supported versions
Only the latest release gets security fixes.

## Reporting a vulnerability
Please do not open a public issue. Use **Security > Report a vulnerability** on this repository (private vulnerability reporting).

Include the MacDock version, your Windows build, steps to reproduce and the impact. Remove personal data from logs before attaching them.

Antivirus false positives are not vulnerabilities; see [docs/ANTIVIRUS.md](docs/ANTIVIRUS.md).
